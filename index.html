📨 Automatic progress report via Telegram

As soon as the daily test is finished, results are sent automatically to a Telegram chat you choose.

How to get a Token & Chat ID:
1) On Telegram, chat with @BotFather → send /newbot → name the bot → receive a Token.
2) Open that exact bot on the account that should receive reports, and press Start (send it any message).
3) In a browser, open: api.telegram.org/bot<TOKEN>/getUpdates to find the Chat ID (the number in "chat":{"id": ...}).
4) Paste the Token and Chat ID into the two fields below, then press Save.
